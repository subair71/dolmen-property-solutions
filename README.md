# Dolmen Property Solutions

Exterior cleaning website for Carlow and the South East of Ireland.

Live site: https://subair71.github.io/dolmen-property-solutions/

## Editing

Edit `generate.py` for page content and `docs/styles.css` or `docs/site.js` for design and interactions. Run `python3 generate.py` to regenerate pages. Commit the updated `docs` directory.

GitHub Pages serves the `/docs` directory on the `main` branch. No build dependencies are required.

The quote form prepares a WhatsApp message for the visitor to review and send; no enquiries are stored on the website.

The official logo and project photographs belong to Dolmen Property Solutions.
